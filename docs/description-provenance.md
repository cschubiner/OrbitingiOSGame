# Store description provenance

The revived description preserves the opening and section structure of the original StutterStep listing: https://www.moddb.com/games/star-stream (2013 listing, retrieved 2026-10-15).

Obsolete references to iPhone 5/iOS 6, Game Center global leaderboards, Kamcord recording and Facebook video sharing were removed. Current device support, local scores, offline play, optional StoreKit purchases and restoring permanent perks are described accurately.

The original repository was created June 22, 2012 and records Clay Schubiner's work with the original team. The 2013 source references original App Store ID 594091366. On October 20, 2026 these source links and the original co-developer's history were added to App Review notes in response to Guideline 4.3(a); the public description was retained. See [the resubmission record](review-resubmission-2026-10-20.md).
